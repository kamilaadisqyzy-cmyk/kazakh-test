# Қазақ тілі — онлайн тест (GitHub Pages + Supabase)

## Мүмкіндіктері

**Оқушы:**
- логинмен тіркеліп, кіреді;
- ашық тесттерді көреді;
- әр тестті бір рет тапсырады;
- бағасын және қай сұрақта қателескенін бірден көреді.

**Мұғалім:**
- барлық нәтижені көреді, сыныппен, тестпен және атымен сүзеді;
- орташа балл мен 5/4/3/2 бағаларының санын көреді;
- нәтижені Excel-ге жүктейді;
- әр оқушының жауабын ашып қарайды;
- оқушыға тестті қайта тапсыруға рұқсат береді;
- **сайттың өзінде жаңа тест құрады**, тестті ашады, жабады немесе өшіреді.

**Қауіпсіздігі:**
- ұпай серверде есептеледі, сондықтан оқушы бағасын бұрмалай алмайды;
- дұрыс жауаптарды оқушылар көрмейді;
- оқушы басқа оқушылардың нәтижесін көре алмайды.

---

## 1-қадам. Supabase жобасын ашу (тегін)

1. https://supabase.com → **Start your project** → GitHub арқылы немесе email-мен тіркеліңіз.
2. **New project** басыңыз:
   - Name: `kaztest`;
   - Database password: кез келген күрделі құпиясөз (сақтап қойыңыз);
   - Region: сізге жақын аймақ (мысалы, Frankfurt).
3. **Create** басып, 1–2 минут күтіңіз.

## 2-қадам. Базаны жасау

1. Сол жақ мәзірден **SQL Editor** → **New query** таңдаңыз.
2. `database.sql` файлының ішіндегісін **түгел** көшіріп қойып, **Run** басыңыз.
3. «Success» шықса, база дайын. Мысал ретінде 10 сұрақтан тұратын бір тест те қосылды.

## 3-қадам. Email растауды өшіру (міндетті!)

Оқушылар email-сіз, тек логинмен тіркеледі. Сондықтан email растауды өшіру керек:

**Authentication** → **Sign In / Providers** (кейде **Providers → Email**) → **Confirm email** қосқышын **өшіріп**, **Save** басыңыз.

## 4-қадам. Кілттерді сайтқа қою

1. **Project Settings → API** (немесе жоғарыдағы **Connect** батырмасы) бөлімін ашыңыз.
2. Екі мәнді көшіріп алыңыз:
   - **Project URL**: `https://xxxx.supabase.co`;
   - **anon public** немесе **publishable** кілт.
   ⚠️ `service_role` немесе `secret` кілтті **ЕШҚАШАН** қоймаңыз!
3. `index.html` файлын ашып, жоғарыдағы жолдарды толтырыңыз:

```js
const SUPABASE_URL = "https://xxxx.supabase.co";
const SUPABASE_KEY = "eyJhbGciOi...";   // немесе sb_publishable_...
```

## 5-қадам. GitHub Pages-ке жариялау

1. https://github.com → **New repository** → атауы `kazakh-test` → **Public** → **Create**.
2. **Add file → Upload files** → `index.html` файлын жүктеңіз → **Commit changes**.
3. **Settings → Pages** бөлімінде: Branch = **main**, папка = **/(root)** → **Save**.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады: `https://GITHUB-АТЫҢЫЗ.github.io/kazakh-test/`

## 6-қадам. Өзіңізді мұғалім ету

1. Сайтқа кіріп, **«Оқушы тіркелуі»** арқылы өзіңізді тіркеңіз (мысалы, логин: `mugalim`).
2. Supabase → **SQL Editor** бөлімінде мына жолды іске қосыңыз:

```sql
update public.profiles set role = 'teacher' where login = 'mugalim';
```

3. Сайттан шығып, қайта кіріңіз. Енді мұғалім панелі ашылады.

Бірнеше мұғалім болса, әрқайсысына осы жолды өз логинімен қайталаңыз.

Осыдан кейін сайт сілтемесін оқушыларға жіберсеңіз болғаны.

## Жиі сұрақтар

**Оқушы құпиясөзін ұмытып қалды.**
Supabase → **Authentication → Users** бөлімінен оқушыны тауып, өшіріңіз. Оқушы сол логинмен қайта тіркеледі. Ескерту: оқушыны өшіргенде оның нәтижелері де өшеді.

**Сыныптар тізімін өзгерту.**
`index.html` ішіндегі `CLASSES` жолын өңдеп, файлды GitHub-қа қайта жүктеңіз.

**Тест сұрақтарын өзгерту.**
Мұғалім панеліндегі **«Жаңа тест»** бөлімінде жаңа тест құрасыз, ал ескісін **«Тесттер»** бөлімінде жабасыз немесе өшіресіз.

**Тегін тарифтің шектеуі бар ма?**
Бір мектептің тесттері үшін тегін тариф жеткілікті. Бірақ жоба бір апта бойы мүлде қолданылмаса, Supabase оны уақытша тоқтатады («pause»). Ондай жағдайда Supabase панеліне кіріп, **Restore** батырмасын басу жеткілікті.
